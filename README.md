## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/DiscJolt.git`
2. `cd DiscJolt`
3. Install in editable mode: `pip install -e .`

## Configuration

DiscJolt is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
